## Resumen
Proyecto para dejar montado el acceso remoto al **equipo personal** de Iñaki
(Windows 11 x64 y Arch Linux, dual/distintas máquinas) desde su móvil Android,
usando herramientas legítimas y sin implicar ningún equipo corporativo ni
evasión de controles de seguridad de terceros.

Top 3 recomendado: **RustDesk** (autoalojable) · **Chrome Remote Desktop**
(sencillez) · **MeshCentral** (autoalojado, más potente).

## Importante
- **No se ha descargado ni instalado nada en el PC de Iñaki.** Esta sesión de
  Claude Code corre en un contenedor Linux remoto en la nube, sin acceso al
  disco `C:` ni a ningún equipo físico del usuario. Todos los enlaces de este
  proyecto son para que el propio Iñaki los descargue en su máquina.
- Este proyecto es exclusivamente para equipos **personales**, no corporativos.
