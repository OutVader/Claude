# Claude — Workspace de Iñaki

Repositorio de trabajo con **Claude Code**: un proyecto por carpeta dentro de
`proyectos/`, más las **skills** reutilizables en `.claude/skills/`.

## Convenciones
- **Español** en toda la documentación.
- Cada proyecto nuevo → carpeta propia en `proyectos/<nombre>/` con su `README.md`,
  contexto y bitácora.
- Nada destructivo sin explicación y confirmación. No se tocan credenciales.
- Skills en `.claude/skills/<nombre>/SKILL.md` con el rol que aplique.
